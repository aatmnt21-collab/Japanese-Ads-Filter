# LYEcosystem-Filter

LINE & Yahoo! JAPAN エコシステムに特化した、**「絶対不具合を起こさない（Zero-Breakage）」高精度DNS広告ブロックフィルター**です。

メッセージ送受信、写真・動画表示（`vos`）、LINE Pay/PayPay、通話などのコア機能や、Googleシステム・各種決済アプリとの通信を100%保護しながら、トーク画面上部やニュース枠の広告・トラッキング通信のみをピンポイントでブロックします。
